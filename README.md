# Portfólio

React + TypeScript + Vite + Tailwind CSS.

## Rodar localmente

```bash
npm install
npm run dev
```

## Editar o conteúdo

- Projetos: `src/data/projects.ts` (use o campo `status` para marcar o que ainda está em desenvolvimento)
- Textos: `src/sections/` e `src/components/Hero.tsx`
- Cores e fontes: `src/index.css`

## Publicar na Vercel

1. Suba o repositório para o GitHub.
2. Na Vercel, importe o repositório.
3. Build command: `npm run build` · Output directory: `dist`.
